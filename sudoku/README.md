# Sudoku

A simple Sudoku game in a single HTML file — no build step, no dependencies.

## Play

Open `index.html` in any browser.

- Click a cell, then click a number (or press 1-9 on your keyboard) to fill it in.
- Press Backspace/Delete (or click Erase) to clear a cell.
- Pick a difficulty (Easy/Medium/Hard) and click **New Game** to generate a fresh puzzle.
- Click **Check** to see if your current entries are complete and correct.

Invalid entries are highlighted in red against the solution as you type.
