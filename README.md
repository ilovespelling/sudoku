# Sudoku

A simple Sudoku game in a single HTML file — no build step, no dependencies.

## Play

Open `index.html` in any browser.

- Click a cell, then click a number (or press 1-9 on your keyboard) to fill it in.
- Press Backspace/Delete (or click Erase) to clear a cell.
- Pick a difficulty (Super Easy/Easy/Medium/Hard) and click **New Game** to generate a fresh puzzle.

Invalid entries are highlighted against the solution as you type, and the game announces itself solved automatically once the board is complete and correct.
